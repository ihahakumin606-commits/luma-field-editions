# LUMA FIELD — Editions & Objects

LUMA FIELD is an experimental storefront for a family of collectible lighting objects by Zheng Jirui (郑吉睿). The site presents L1, L2, L3 and A1 as one coherent product system built around cold metal, mineral weight and a smoked-amber pivot node.

## Live site

[luma-field-l1-object-archive.ihahakumin606.chatgpt.site](https://luma-field-l1-object-archive.ihahakumin606.chatgpt.site)

## Highlights

- Cinematic “Amber Threshold” opening sequence
- Pointer parallax and scroll-responsive hero composition
- Responsive product catalogue and filtering
- Product detail dialog and persistent local selection list
- Reduced-motion support
- No framework or build step required

## Run locally

Clone the repository and serve its root with any static web server.

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
