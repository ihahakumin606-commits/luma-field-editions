# THRESHOLD FIELD

**DEFINE THE IN-BETWEEN.**

An English-language, static art-object collection for T01–T06 by Jirui Zheng. This folder contains the approved website and original-resolution image assets, including the continuous, gently zooming opening scene.

## Public website

[Open THRESHOLD FIELD](https://threshold-field-objects.ihahakumin606.chatgpt.site/)

The public website can be opened directly in a normal browser. Visitors do not need a GPT or GitHub account. Its current host is Sites, not GitHub Pages.

## Independent static hosting

Serve this folder with any static web server. It contains no framework, build step, external API, remote font, or sign-in requirement. Project lists and notes remain local to each visitor's browser; they do not place orders or transmit inquiries.

The original LUMA website at the repository root remains unchanged. To host both collections on GitHub Pages, enable **Settings → Pages → Deploy from a branch → main → /(root)**. THRESHOLD will then be available under the `threshold-field/` path. GitHub Pages has not been enabled by this source upload.
